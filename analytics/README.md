# Scinode Аналитика — расчёт показателей (этап B)

Программа на Python (только стандартная библиотека) раз в месяц считает
показатели вузов и научных организаций Узбекистана по открытым данным
[OpenAlex](https://openalex.org) (лицензия CC0) и публикует файлы с цифрами на
GitHub Pages. Графики и PDF-отчёт рисует приложение Scinode.

- Запуск на GitHub: `.github/workflows/analytics.yml` — 3-го числа каждого месяца,
  после изменений в `analytics/` в main и вручную (Actions → Scinode Analytics →
  Run workflow).
- Адрес данных: `https://x9096730-spec.github.io/scinode/analytics/v1/index.json`
  и `…/analytics/v1/orgs/<id>.json` (`UZ.json` — вся страна).
- Ключ OpenAlex — секрет репозитория `OPENALEX_API_KEY` (в коде его нет).
  Один расчёт — около 45 запросов OpenAlex на организацию, всего около 6 500
  (≈ $0,65 из $1 дневного бесплатного лимита ключа, 10 000 запросов), плюс
  бесплатные запросы к OpenCitations, Crossref и ROR. Перед стартом программа
  проверяет остаток лимита (`X-RateLimit-Remaining`) и не начинает, если его не
  хватит; если лимит кончился посреди расчёта (ответ 429 с долгим `Retry-After`),
  расчёт сразу останавливается и ничего не публикует — на сайте остаются прошлые
  данные. **Совет:** для GitHub лучше отдельный бесплатный ключ, чтобы проверки и
  приложение на телефоне не делили один дневной лимит.

Не подключено, и почему:
- **SCImago (SJR, квартили)** — данные Scopus; Elsevier запрещает коммерческое
  использование метрик журналов без письменного разрешения.
- **Список исключённых из Scopus журналов** — данные Elsevier без открытой лицензии.
- **Лейденский рейтинг, открытая версия (CC0)** — можно, но данные лежат на
  zenodo.org (около 2,2 ГБ), а этот адрес закрыт в среде разработки.

Локально:

```bash
cd analytics
python -m pytest -q tests                      # тесты на записанных ответах
OPENALEX_API_KEY=… python -m scinode_analytics.build --out ../site --limit 3
python -m scinode_analytics.build --only I4405284798 --record /tmp/rec  # записать образцы
```

## Какие организации

Все организации с `country_code:UZ` в OpenAlex, кроме компаний (`type:company`),
у которых за окно расчёта не меньше 100 работ (по `counts_by_year`). Работы
организации — фильтр `authorships.institutions.lineage:<id>`: вместе с её
подразделениями (например, институты Академии наук входят в Академию).

## Методика

Окно для показателей — **5 последних полных лет** (в 2026 году — 2021–2025).
Публикации по годам показываются за 10 лет и текущий (неполный) год.

| Раздел | Как считается |
|---|---|
| Публикации по годам | `group_by=publication_year`; отдельно `type:article` и `type:conference-paper`, остальное — «другое» |
| Типы работ | `group_by=type` за окно |
| Открытый доступ | `open_access.is_oa:true` по годам; виды доступа — `open_access.oa_status` (diamond, gold, hybrid, green, bronze, closed) |
| PP(top 10%), PP(top 1%) | доля работ в мировом топ-10 % / 1 % по цитируемости в своей области и году (`citation_normalized_percentile`), как в Лейденском рейтинге CWTS. Знаменатель — работы, для которых OpenAlex посчитал процентиль. Мировой уровень — 10 % и 1 % |
| FWCI | нормированная цитируемость (1,0 — мировой уровень). Показываем долю работ, которые **хоть раз процитированы** (FWCI > 0), и долю работ **выше мирового уровня** (FWCI > 1) — фильтрами `fwci:>0`, `fwci:>1`, знаменатель `fwci:>-1`. Медиану не показываем: у большинства организаций Узбекистана больше половины работ ещё не цитировались, и медиана равна 0 (проверено на 37 вузах 5 ноября 2026), а среднее искажают единичные «звёздные» статьи |
| Собственные (ведущие) работы | работы, где автор для переписки — из организации (`corresponding_institution_ids:<id>`): их число, доля и PP(top 10%) / PP(top 1%). Это главный показатель собственного уровня: проверка 5 ноября 2026 показала, что PP(top 10%) по всем работам завышен почти вдвое «гостевым» соавторством (НУУз 9,0 % → 5,1 %, ТГЭУ 11 % → 5,2 %, пед. университет им. Низами 8,8 % → 3,5 %). Для страны такого фильтра в OpenAlex нет |
| Сильные направления | разделы OpenAlex (subfield) по `primary_topic`: всего работ, собственных работ и PP(top 10%) собственных работ. «Сильное» — не меньше 30 собственных работ с процентилем и **нижняя граница 95 % интервала Уилсона** доли в топ-10 % выше 10 %. Пометка «в основном соавторство» — собственных работ в разделе меньше 30 %. Пример: у пед. университета им. Низами по «биомедицинской инженерии» 192 работы и 28 % в топ-10 %, но собственных работ 7 и ни одной в топ-10 % — раньше это ошибочно выходило «сильным» |
| Мегаколлаборации | работы с числом авторов больше 100 (`authors_count:>100`, CERN и т. п.): сколько их, сколько в топ-10 % и PP(top 10%) без них (у Института ядерной физики 14,6 % → 9,1 %) |
| Надёжность данных | отозванные статьи (`is_retracted:true`, данные Retraction Watch в OpenAlex; по Узбекистану за 2021–2025 — 639); доля работ, у которых основное место публикации — репозиторий (Zenodo и т. п., без рецензирования журнала) |
| Партнёры | страны (`authorships.institutions.country_code`, без своей) и организации (`authorships.institutions.lineage`, без самой организации и её подразделений); доля международных работ — `countries_distinct_count > 1` |
| Ведущие авторы | 20 авторов с наибольшим числом работ организации за окно; h-индекс, работы и цитирования — из профиля автора OpenAlex (за всю карьеру) |
| Журналы | 20 источников с наибольшим числом работ; отметка DOAJ (`is_in_doaj`), тип (журнал, репозиторий, конференция), издатель; доля работ в журналах из DOAJ |
| Проверка цитирования | 10 самых цитируемых работ организации за окно (от 10 цитирований): **самоцитирование авторов и журнала** — отметки `author_sc` / `journal_sc` OpenCitations (CC0, `api.opencitations.net/index/v2/citations/doi:…`); **откуда цитирования** — `cites:<W>` с `group_by=authorships.institutions.lineage` в OpenAlex: доля цитирований из своей организации и из самой частой чужой. Тревожный признак — доля больше 50 % (от 10 цитирований). Это повод присмотреться, а не обвинение |
| Проверка журналов | у 20 главных журналов: есть ли журнал в Crossref (`api.crossref.org/journals/<ISSN>`, 404 — нет, у статей нет DOI) и **резкий рост объёма** по `counts_by_year` OpenAlex — в 3 раза и больше за 3 года при 500+ работах в год (частый признак «конвейера» публикаций) |
| ROR | официальные названия на ru/uz/en, год основания, статус, связи (`api.ror.org/v2/organizations/<ror>`, CC0) |
| Вся страна | те же разделы по фильтру `authorships.institutions.country_code:UZ` — для сравнения |

**Оговорка (показывается в приложении):** индикаторы рассчитаны по открытым
данным OpenAlex; возможны неточности привязки авторов и организаций, а часть
работ (особенно последних лет) — материалы конференций и местные журналы.
Это не замена курируемым базам (Scopus, Web of Science), а быстрая и прозрачная
оценка по открытым данным.

## Формат файлов (schema 1)

`index.json`: `schema`, `generated` (дата), `source`, `window` [с, по], `years`
[с, по], `country`, параметры расчёта, `orgs` — список организаций (`id`, `name`,
`acronyms`, `alt`, `type`, `ror`, `city`, `lat`, `lon`, `url`, `works_window`,
`works_total`, `citations_total`, `h`, `i10`), `failed` — что не посчиталось.

`orgs/<id>.json`: те же общие поля, `org` и разделы `works`, `years`, `types`,
`oa`, `citation` (`known`, `top10`, `top1`, `pp_top10`, `pp_top1`, `fwci`, `lead` —
собственные работы, только у организаций; `mega` — мегаколлаборации),
`integrity` (`retracted`, `source_types`), `citation_check` (только у
организаций), у журналов — `growth`, `crossref`, `crossref_publisher`, у
организации — `ror_data` (`names`, `established`, `status`, `relationships`), в `topics` — `lead`, `lead_share`,
`lead_known`, `lead_top10`, `lead_pp_top10`,
`collab` (`intl`, `intl_share`, `countries`, `partners`), `authors`, `journals`
(`doaj`, `known`, `doaj_share`, `top`), `topics`.

Поля можно добавлять без смены схемы (старые версии приложения их не читают);
менять или удалять — только с новой схемой и папкой `v<N>`.

Образцы для тестов — настоящие ответы OpenAlex от 5 ноября 2026
(`tests/fixtures/openalex/`, без ключа).
