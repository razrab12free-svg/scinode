### Важно знать
- **OpenAlex без ключа почти не работает.** Без ключа все пользователи с одного
  IP-адреса делят бесплатный бюджет $0.10 в день; с личным бесплатным ключом — $1 в день.
  Ключ вводится в «Профиль → Ключ OpenAlex». Для карты науки (задача 4) ключ
  обязателен; при разработке нужен ключ для проверки запросов.

### Заметки по карте науки
- OpenAlex не умеет фильтровать организации по прямоугольнику карты, поэтому при
  приближении карта подгружает организации континента в центре экрана, а при выборе
  страны — этой страны.
- В данных OpenAlex есть явные ошибки (лаборатория с 44 млн работ) — организации
  с числом работ больше 5 млн отсекаются.
- Тайлы OpenStreetMap бесплатны только при умеренной нагрузке; при росте аудитории
  перейти на свой сервер тайлов или бесплатный тариф MapTiler / Stadia Maps.

### Отложено (не критично)
- Поиск участников фильтрует страну после выборки 100 профилей — при росте числа
  участников часть подходящих не покажется. Нужен запрос с фильтром в Firestore.
- Размер шрифта в приложении ограничен 120% системного (сознательное решение
  для вёрстки; пересмотреть при доработке доступности).
- На самых узких экранах с максимальным шрифтом длинные узбекские слова в плитках
  главной переносятся по слогам.
